# SEIS-606 App Brainstorm

Recipe app:
- Store recipes in multiple formats (photos of physical recipes, text, links to online recipes).
- Ingredient-based search.
- Sharable with others.

Library checkout system:
- Users search and check out books from the catalogue.
- Borrowing history has retention rules.

Theater scene visualizer:
- Given a playtext, generate a visualization showing which scenes contain which characters.

Unusual activity detector:
- A simulation models human services case workers accessing client cases. The app is a monitoring tool that checks the activity logs for unusual worker activity.

Poetry builder game:
- The user writes a poem line by line, using a combination of pre-written and user-entered lines.
